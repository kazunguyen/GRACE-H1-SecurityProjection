# GRACE H1 — Security Projection

Học projection bảo mật nhỏ trên CodeT5 đóng băng, dùng để chọn demonstration rồi chạy đủ GRACE: candidates → semantic shortlist → lexical/AST rerank → CPG prompt → LLM → evaluation.

Dataset hỗ trợ: Devign và ReVeal theo snapshot dự án. Dữ liệu/cache được copy vào project này và bỏ qua Git; code/docs/notebook được commit theo từng bước. Chưa có origin.

Chi tiết triển khai và notebook sẽ được bổ sung ở các commit tiếp theo.
